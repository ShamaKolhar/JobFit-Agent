# Regional Sales Dashboard

Type: Portfolio project
Domain: Retail analytics
Dates: March 2024 – May 2024
Status: Complete

## What it is
An interactive dashboard that helps a fictional retail chain see which regions and product lines are growing or declining, replacing a set of manually updated spreadsheets.

## What I did
- Cleaned and merged three years of messy sales exports using Python (pandas)
- Wrote SQL queries to aggregate revenue by region, product line and month
- Built an interactive dashboard in Tableau with region filters and trend charts
- Documented data assumptions and refresh steps in a short README

## Tools
Python, pandas, SQL (SQLite), Tableau

## Skills shown
Data cleaning, SQL aggregation, dashboarding, data storytelling, documentation

## Outcome
Produced a working dashboard that replaced the manual spreadsheet process in the sample scenario and surfaced two under-performing regions. Built on a synthetic dataset, so no real business results.
